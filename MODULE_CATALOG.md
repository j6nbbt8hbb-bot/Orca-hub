# Orca Module Catalog

The current registry contains **118 registered module placeholders**.

Categories:

- Combat
- Movement
- Player
- Render
- World
- Exploration
- Storage
- Search
- Utility
- Performance
- Multiplayer
- Troll
- Cosmetics
- HUD
- Scripts
- Configs
- AI
- Settings

Every registry entry has a name, description, category, enabled state, keybind field, lifecycle hooks, and GUI representation.

The project intentionally keeps gameplay-cheat/anti-cheat-bypass functionality out of the placeholder implementations. Streamer Mode is for privacy/UI masking only.
